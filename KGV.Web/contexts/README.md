# Gemeinsame React-Kontexte

Dieser Ordner ist für bereichsübergreifenden UI-Kontext vorgesehen, insbesondere
den später aus `Workspace` herauszulösenden Saison-, Mitglieds- und
Parzellenkontext. Persistiert wird weiterhin nur der Saisonkontext; konkrete
Mitglieder und Parzellen werden nicht dauerhaft im Browser gespeichert.
