# Browser-Infrastruktur

Dieser Ordner ist für wiederverwendbare, rein technische Browserfunktionen
vorgesehen, etwa Medienfähigkeiten, IndexedDB und Netzwerkerkennung. Fachliche
Scanner- oder Zählerabläufe verbleiben außerhalb dieses Ordners bei ihrer
Fachgruppe; die lokale Foto-Warteschlange bleibt technische G15-Infrastruktur.
